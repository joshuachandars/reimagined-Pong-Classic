# PONG

A classic Pong game that runs in the browser. It uses plain HTML, CSS and JavaScript, with no build step or dependencies.

## Play

Open `index.html` in any modern browser. If you want to try the game out, play it at:

https://joshuachandars.github.io/reimagined-Pong-Classic/

## Modes

- **1 Player:** play against a bot. The bot is slightly beatable.
- **2 Players:** two players share one keyboard.

## Controls

| Action        | Player 1 (left) | Player 2 (right) |
|---------------|-----------------|------------------|
| Move up       | `W`             | `↑`              |
| Move down     | `S`             | `↓`              |

- **Menu:** `W`/`S` or `↑`/`↓` to choose a mode, then `Space` or `Enter` to start.
- The first player to reach **11** wins.

## Project structure

```
index.html   page markup
style.css    page styles
game.js      game logic, rendering, sound and bot AI
```
